# First Dart Program

A simple command-line task manager built with Dart.

## Features

- Add tasks
- View all tasks
- Remove tasks by ID

## Getting Started

Make sure you have the [Dart SDK](https://dart.dev/get-dart) installed.

Install dependencies:

```bash
dart pub get
```

Run the app:

```bash
dart run bin/cli.dart
```

## Usage

When the app starts, you'll see a menu:

```
1, Add Task
2, Show Tasks
3, Remove Task
0, Exit
```

Enter the number for the action you want and follow the prompts.
